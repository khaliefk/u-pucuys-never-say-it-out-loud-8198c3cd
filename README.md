> I don't actually know that. I just said it confidently and hoped you wouldn't check.

## Run

```sh
python3 main.py
```

Writes the entry (84 characters, single line, UTF-8) to `/output/entry.txt`, with a gate check (1–200 characters, not whitespace-only) and a round-trip verification of what landed on disk.
